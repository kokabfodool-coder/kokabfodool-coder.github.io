Teaching numbers, addition and subtraction

Use objects and pictures to build counting and arithmetic skills, then practise with Fudool Market, number games and worksheets.

Touch each object as you count

Set out 5 blocks. Ask the child to touch one block per count. Rearrange the same blocks and ask the child to check whether the total has changed.

Model addition and subtraction

Put 4 blocks next to 3 blocks and write 4 + 3 = 7. Remove two blocks, then ask the child to write 7 − 2 = 5 and explain what each number represents.

Find the total and change

Make a paper shop with two prices, 6 and 7. Add the prices, then find the change from 20. The child can count on from 13 to 20 to check the result.
