How to play and what you practise

Arrange direction buttons into a short program, then run it. If Robo stops at an obstacle, check the commands one at a time and fix the instruction.

  • 3–5 yearsMove Robo on a small grid (Levels 1–5)
  • 6–7 yearsSequence direction commands on longer paths (Levels 6–12)
  • 8–10 yearsPlan around obstacles and debug commands (Levels 13–22)
